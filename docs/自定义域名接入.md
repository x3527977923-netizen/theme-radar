# 自定义域名接入（三步，10 分钟）

> 现在的地址是 `https://x3527977923-netizen.github.io/theme-radar/`（永久有效，但国内偏慢）。
> 换成自己的域名后，网址更短更好记，国内速度也会明显改善。

## 第一步：买域名

| 平台 | 便宜后缀参考 | 备注 |
|---|---|---|
| 阿里云（万网） | `.top` `.cn` `.xyz` | 首年促销常见 1~20 元；续费 30~60 元/年 |
| 腾讯云 | 同上 | 同上 |
| Cloudflare Registrar | 无首年促销，成本价 | 需要信用卡 |

**注意：**
- 首年便宜、续费回原价，是行业惯例
- `.cn` 需要**实名认证**（个人身份证即可，几小时通过）
- **不需要 ICP 备案**（GitHub Pages 服务器在境外）

建议买个短一点的，比如 `ticaideng.top`、`kanpan.cn` 之类。

## 第二步：在 GitHub 里填域名

打开 https://github.com/x3527977923-netizen/theme-radar/settings/pages

在 **Custom domain** 里填入你买的域名（例如 `ticaideng.top`），点 **Save**。

保存后仓库里会自动出现一个 `CNAME` 文件，内容就是你的域名。

## 第三步：在域名商那里加解析

进入域名的 **DNS 解析** 页面，加这几条：

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `x3527977923-netizen.github.io` |

保存后等 10 分钟到 2 小时（DNS 生效），然后回到 GitHub Pages 设置页：

1. 等 **DNS check successful** 变绿
2. 勾上 **Enforce HTTPS**（证书自动签发，等几分钟）

## 验证

```bash
curl -I https://你的域名/
```

返回 `HTTP/2 200` 就成功了。

## 加强版（可选，国内更快）

域名解析交给 **Cloudflare** 托管：

1. 注册 Cloudflare 免费账号，添加站点（填你的域名）
2. Cloudflare 会给你两个 NS 地址，去域名商改成这两个
3. 等生效后，在 Cloudflare 的 DNS 里同样加上面的 A/CNAME 记录
4. **开启橙云（Proxied）** —— 这样国内访问走 Cloudflare 节点，比直连 GitHub 快且稳

⚠️ 开了橙云后，Cloudflare 的 SSL 模式选 **Full**（不要选 Flexible，否则会循环重定向）。

## 换域名后要改的地方

| 位置 | 内容 |
|---|---|
| 宣传词 | 把网址换成新域名 |
| 仓库 `README.md` | 「站点地址」一节 |
| 技能/笔记 | 如果有记录旧地址 |

## 如果以后想换回 GitHub 地址

删掉仓库里的 `CNAME` 文件即可，`github.io` 地址一直都在，不会失效。

## 自动化脚本（可选）

配好域名后，可以用脚本一次搞定「写 CNAME + 提交」：

```bash
python add-domain.py 你的域名
```

（脚本会先确认这个域名当前能否正常访问 GitHub Pages 的默认地址，再写入 CNAME，避免配错导致站点打不开。）
