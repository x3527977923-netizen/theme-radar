# 题材雷达 · 盘后整理

收盘后三分钟，看懂今天哪些题材表现突出、和上一交易日相比有什么变化。

## 这是什么

一个纯静态网站：每个交易日收盘后，由 GitHub Actions 自动抓取公开行情数据，生成 JSON 并部署到 GitHub Pages。

- 不需要服务器，不需要常开电脑
- 数据来源：新浪财经、腾讯财经的公开行情接口（非交易所授权数据）
- 只陈述事实：涨了多少、比上一交易日变了多少、板块里哪几只股票涨幅靠前
- 不预测涨跌，不构成投资建议

## 目录结构

```
site/                 ← 部署到 Pages 的静态站点
  index.html
  assets/             ← 前端打包产物（Vue 3 + Vite）
  data/
    home.json         ← 首页：最近交易日 + 5 个值得看的题材
    sectors.json      ← 全部题材当日行情 + 较上一交易日变化
    stocks.json       ← 每个题材涨幅靠前的成分股
    indices.json      ← 主要指数
    history.json      ← 近 30 个交易日 × 题材矩阵
    _daily/           ← 每日原始快照（用于累积历史，勿删）
scripts/fetch_data.py ← 数据生成脚本
.github/workflows/daily.yml ← 每个交易日 15:10 自动运行
```

## 本地预览

```bash
python scripts/fetch_data.py        # 抓数据（会写 site/data）
python -m http.server 8030 -d site  # 打开 http://127.0.0.1:8030
```

## 数据口径

| 项目 | 口径 |
|---|---|
| 交易日 | 取自行情返回的最新成交日，周末/节假日自动回退到上一个交易日 |
| 题材涨跌幅 | 新浪概念板块的板块涨幅 |
| 较上一交易日 | 当日涨幅 − 上一交易日涨幅，单位「个百分点」 |
| 涨幅靠前 | 板块内当日涨幅居前的个股，不代表涨停或行业地位 |
| 缺失数据 | 显示「暂无数据」，不填 0 |
